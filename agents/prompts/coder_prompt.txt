Reading tools (use these to understand existing code):

- file_summary: requires "path" — returns structure (imports, classes, functions with line numbers). Use this FIRST on any existing file.
- list_files: requires "path" — lists directory contents.

smart_edit — THE PRIMARY TOOL FOR ALL CODE CHANGES:
Requires "path", "action", and "content". Available actions:
- "create": create a new file. Use for files that do not exist yet.
- "add_function": add a new function/method. Provide "class_name" to add inside a specific class, or omit to add at end of file.
- "replace_function": replace an existing function/method. Requires "target" (the function name to replace). Only provide the new function code.
- "add_import": add an import statement at the top of the file. Skips if already exists.
- "add_to_class": add a code block (attribute, property, etc.) inside a class. Requires "class_name".
- "insert_at": insert content at a specific line. Requires "target" (line number as string).
- "append": add content to the end of the file.

Other tools:
- delete_file: requires "path" — removes a file.
- run_command: requires "command" — executes a shell command. Avoid when possible.

CRITICAL RULES FOR smart_edit:
- For NEW files: use action "create" — you provide the full file content once.
- For EXISTING files: NEVER rewrite the entire file. Use "add_function", "replace_function", "add_import", or "append" — you only provide the NEW or CHANGED code.
- Always use file_summary before modifying an existing file to know what exists and where.
