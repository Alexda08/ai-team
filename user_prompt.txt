Necesitamos desarrollar una app privada/personalizada para Shopify orientada a la generación de Draft Orders sin que el cliente tenga que pasar por el checkout estándar de Shopify.

La app deberá permitir que determinados usuarios, previamente autorizados desde la propia aplicación, puedan acceder a una funcionalidad especial dentro de la tienda. Esta funcionalidad añadirá nuevas opciones en el basket/cart, visibles únicamente para los usuarios seleccionados, con el objetivo de solicitar o generar pedidos en formato draft order bajo una lógica de negocio específica.

Además, será necesario poder marcar y gestionar qué productos son aptos para este flujo, de manera que no todo el catálogo participe necesariamente en la generación de Draft Orders. Esta configuración deberá poder administrarse desde la propia app, permitiendo definir con precisión qué productos, variantes o grupos de productos pueden utilizar este circuito especial.

La solución no será una app simple, sino una implementación compleja y con lógica de negocio avanzada, ya que requerirá:

una integración profunda con Shopify,

control de visibilidad de funcionalidades según usuario,

gestión de productos habilitados para draft orders,

generación de pedidos preliminares sin pasar por el checkout nativo,

y una arquitectura backend propia en nuestros servidores para soportar la lógica, reglas, validaciones, permisos, almacenamiento y comunicación con la API de Shopify.

El backend deberá actuar como núcleo de la aplicación, centralizando la autenticación, la autorización de usuarios, la gestión de configuraciones, la validación de condiciones de negocio y la creación de los Draft Orders en Shopify. También deberá contemplarse la seguridad, trazabilidad de acciones, escalabilidad y mantenimiento futuro de la solución.

En resumen, buscamos una app a medida, robusta y escalable, que permita habilitar un flujo alternativo de compra para ciertos usuarios y ciertos productos, manteniendo el control desde una plataforma propia conectada con Shopify.

Versión más técnica / tipo alcance funcional

Se requiere el desarrollo de una app custom para Shopify con backend externo, destinada a habilitar un flujo de compra alternativo basado en Draft Orders, evitando el paso por el checkout estándar de Shopify.

La aplicación deberá contemplar como mínimo los siguientes bloques funcionales:

Gestión de usuarios autorizados
La app deberá permitir definir qué usuarios podrán visualizar y utilizar las opciones especiales asociadas a la generación de Draft Orders. Esta autorización no será global, sino controlada desde la propia app.

Opciones condicionales en cart/basket
Para los usuarios autorizados, deberán mostrarse en el carrito una o varias acciones específicas relacionadas con la solicitud o creación de Draft Orders. Estas opciones no deberán ser visibles para el resto de usuarios.

Gestión de productos habilitados
Será necesario identificar y administrar qué productos o variantes pueden entrar en este flujo especial. La app deberá permitir marcar estos productos y mantener esta configuración de forma centralizada.

Creación de Draft Orders sin checkout estándar
El sistema deberá generar Draft Orders en Shopify sin requerir el paso por el checkout nativo, respetando las reglas de negocio definidas para este flujo.

Backend externo propio
Debido a la complejidad del proyecto, será imprescindible un backend alojado en nuestros servidores para gestionar:

autenticación y permisos,

lógica de negocio,

comunicación con Shopify,

configuración de usuarios y productos,

persistencia de datos,

logs y trazabilidad,

y posibles ampliaciones futuras.

Escalabilidad y mantenibilidad
La solución deberá plantearse con una arquitectura sólida, preparada para evolucionar y soportar nuevas reglas, integraciones y casos de uso.
