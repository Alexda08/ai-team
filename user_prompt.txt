Haz una todo-list en Python con estas características:

Una clase TaskManager.
Cada tarea tiene:
id
title
status (pending o done)
Operaciones básicas:
agregar tarea
listar tareas
marcar tarea como completada
eliminar tarea
Validaciones mínimas:
no permitir títulos vacíos
no permitir tareas duplicadas por título
Un menú en consola para usar el programa.
