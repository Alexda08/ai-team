Quiero una API REST en Node.js con TypeScript puro (sin framework, solo http nativo + ts-node).

3 endpoints:
- GET /tasks — lista todas las tareas (array en memoria)
- POST /tasks — crea una tarea con { title, priority: "low"|"medium"|"high", dueDate }
- DELETE /tasks/:id — elimina por id

Requisitos:
- Un archivo de tipos compartido (Task, Priority, ApiResponse)
- Un servicio con la lógica de negocio separada del router
- Validación: title obligatorio, priority debe ser uno de los 3 valores, dueDate debe ser fecha futura
- El router debe usar pattern matching con regex para las rutas
- Respuestas siempre en formato { success: boolean, data?: T, error?: string }
- IDs generados con crypto.randomUUID()
